# Peri v2 Live2D assets

Upload the Peri v2 Cubism files here.

Keep the `.model3.json`, `.moc3`, textures, motions, expressions, and any related metadata together in this folder. After the upload is complete, the model can be wired into `assets/live2d/registry.json` with the final entry file name.

Optional: add `background.webp` here to use it behind Peri v2 in the companion stage. The registry already points at `assets/live2d/peri-v2/background.webp`.

`background.png` is kept only as a compressed compatibility alias for older cached app chunks or registry reads that still request the old filename.
