# Story Mode Banner Videos

Drop optimized story-mode banner videos in this folder so future AI edits can
wire them into the campaign/story UI without hunting through the repo.

Recommended path format:

```text
assets/videos/story-mode/banners/<world-or-scene>-banner-01.mp4
```

Good examples:

```text
assets/videos/story-mode/banners/haven-banner-01.mp4
assets/videos/story-mode/banners/zombie-banner-01.mp4
assets/videos/story-mode/banners/frostwood-intro-banner-01.mp4
```

Keep web-ready copies here, not huge source exports. Prefer muted H.264 MP4,
short loops, and poster images beside the video when possible:

```text
assets/videos/story-mode/banners/haven-banner-01.mp4
assets/videos/story-mode/banners/haven-banner-01.jpg
```

When wiring a banner into code or data, reference the file with the same
repo-relative path shown above.
