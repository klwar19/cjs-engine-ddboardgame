Guardrails:

- `tools/art-budget.json` keeps dimension caps for curated image targets and byte caps for source media categories.
- `test_art_budget.js` validates image dimensions and source category caps without requiring a build.
- `npm run size:check` validates the built payload against `tools/build-size-baseline.json` and enforces the same source category caps so a baseline bump cannot hide oversized media.
